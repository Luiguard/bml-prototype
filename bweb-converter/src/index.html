Willkommen im Binären Web

Eine radikale Neuerfindung der Webarchitektur. Schneller, sicherer und deterministischer.

Achtung: Diese Seite wird gerade von einer WebAssembly-VM aus einem binären BWEB-Paket gerendert – nicht vom klassischen DOM.

Was ist BWEB?

BWEB (Binary Web) ist ein vollständig präkompiliertes Webformat. Anstatt dass dein Browser tausende Zeilen HTML, unvorhersehbares CSS und schwerfälliges JavaScript parsen, berechnen und layouten muss, liefert BWEB das fertige Ergebnis. Ein C-ähnlicher Pointer-Baum (BDT) und fertig berechnete Layout-Blöcke (BLB) sagen der Render-Engine (Canvas/WebGL) direkt, was wohin gezeichnet wird.

Die 5 Säulen der Architektur

BML (Binary Markup)

Ersetzt HTML. XML-Knoten und Tags werden zu 1-Byte Opcodes reduziert. Kein Parsing-Overhead mehr.

BDT (Binary DOM Tree)

Der Strukturbaum im Speicher. Eine extrem flache Array-Struktur, navigiert über 16-Bit Pointer. Eliminiert Node-Traversal-Latenzen.

BLB (Binary Layout)

Das Ende des CSS-Cascadings. Statische 60-Byte-Blöcke, die dem Renderer die finalen Box-Metriken ohne Engine-Berechnung diktieren.

BIB (Binary Images)

Rohe Pixelpipelines. Original komprimierte Medien (PNG/JPG), die asynchron direkt über die GPU-Decodierer auf das Canvas gefeuert werden.

BVS (Binary Video)

Zero-Latency Video Playback. Kein MP4-Overhead. Reine Multiplex-Frames direkt an die WebCodecs API.

Benchmark: DOM vs. BWEB

Klassisches DOM (Parsen, Stylen, Layouten, Paint)
~ 850ms (LCP)
BWEB Engine (WASM Pointer-Read + Canvas Paint)
~ 120ms (LCP)

Die BWEB-Struktur entlastet den Main-Thread komplett. Interaktionen, Reflows und Repaints erfolgen innerhalb der WASM-Sandbox, abgekoppelt von browserinternen Layout-Thrashing-Problemen.
